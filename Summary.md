# SOHO-Network-Lab
Cisco Packet Tracer lab environment that tests real troubleshooting flows like finding an offline printer, verifying VLANs and checking whether an issue is local or upstream.
The lab notes in this repository navigate the exploration of the network architecture through CLI commands and then demonstrate a troubleshooting workflow, mostly using one of the network switches and the network's router/default gateway. This lab helps to learn how Cisco commands work, including the differences between user EXEC, privileged EXEC, global config and interface config, proving where a device is, inspecting configurations, checking ports and VLANs, tracing devices, looking upstream, reviewing health signals and more. The first section of the lab notes regard building the network and the configurations of devices. (To view the topology, see SOHO Network VLANs.pkt) (To view device CLI configurations view configs.md) Several basic commands are used to view and verify configurations of devices, inspect interfaces and VLANs, find devices on the network, view the spanning trees of VLANs, and view the health and logs of connections. These important commands are used and demonstrated in the lab notes before moving on to troubleshooting workflows for three different scenarios/support tickets.
